## 4. THE BLOCKER — the s-march (`march_s.py`), and its defect ledger

**The idea:** marching in physical variables costs (T−t)^(−2c_l) ≈ 10^5.84 DOF
per decade (Theorem 2a) — every machine dies at ~1.3 e-foldings. In
dynamically-rescaled coordinates (normalize sup|U|=1, HWHM=1; A, L set by the
normalization) the collapse stops moving: **one e-folding = O(1) of rescaled time
s at fixed grid.** 20 e-foldings costs 20 units of s, not 10^35 DOF.

**Why it's small, not a rewrite:** `polar_cornerreg.py` already carries c_l, c_ω
as unknowns and already has the `c_l·(y·∇)` and `c_ω·` rescaling terms in its
residual rows. **F(z)=0 already means ∂_s A = ∂_s B = 0** — the steady solver IS
the fixed point of the rescaled dynamics. Marching = backward Euler = add `I/Δs`
to two diagonal blocks.

**Defect ledger (from the EJA preflight against `NOTE_CLAIMS.md`):**
- **T1 — mass-matrix weight. RESOLVED.** S1: E = I on live transport rows (sympy
  on coded RO′/RB′ to 5.8e-157; c_ω-column identity exact). So `(A−A_old)/Δs = RO`
  is structurally correct. W ≡ 1.
- **T2 — stale pins. OPEN (easy).** `rT_pin` rows overwrite field rows with
  `A[r]−A0[r]=0`, pinning to the SEED. `march_s.py` correctly excludes them from
  the mass term but leaves them pinned to a stale A0, so those points can't
  evolve. **Fix:** refresh the pin reference each step, or replace pins with the
  corner conditions.
- **T3 — the sign. RESOLVED.** S4: Hurwitz certified via Lyapunov (residual
  4.8e-16, Cholesky ok), eigenvalue-free. The sign is fixed by **matching S4's
  Lyapunov convention**, not by marching-and-watching. (Do NOT determine it from
  eigenvalues — see refusals.)
- **T4 — index-2 DAE. OPEN, and the serious one.** S1 grades the linearization as
  a descriptor pencil (E, J), E a 0/1 diagonal mask, **Hessenberg index 2** (QZ:
  376 finite / 346 infinite, closing exactly). Naive backward Euler on an index-2
  DAE suffers order reduction and can be unstable — **the defect that yields
  smooth, plausible, WRONG trajectories.** `march_s.py` currently treats it as an
  ODE with algebraic rows bolted on. **Fix:** index-aware integration on ker(Cg),
  **reusing `polar_spectrum.py`'s existing projectors** (`project`,
  `project_oblique`, `restrict`, `prolong` — they already respect S2/S3).
  **DO NOT hand-roll a projector.**

**Build order for M1 (from `HANDOFF_SMARCH.md`):**
1. Fix T2: refresh pin reference each step, or swap pins → corner conditions.
2. Fix T4: index-aware integration on ker(Cg) reusing the four existing
   projectors above.
3. Calibrate the sign against S4's Lyapunov convention, not by marching.

## 6. A PARALLEL CHEAP TRACK — exploratory, non-decisive, eigenvalue-free

These attack the *reason* measurements are inconclusive without first fixing the
index-2 march. None is decisive; each could surface structure worth knowing.
Ranked by sharpness.

1. **Re-measure the existing orbit data in the Lyapunov P-norm.** The 5807× is in
   the raw collocation norm. But `LᵀP+PL=−I` means `V(x)=xᵀPx` has
   `dV/dt = −‖x‖² < 0`: in the **P-norm the linear flow cannot grow — the
   transient vanishes by construction.** Project each orbit onto x = U − U\*, plot
   `‖x(s)‖_P` vs s: monotone decrease → linear settling; ANY growth → genuinely
   nonlinear/wandering (linear can't grow in P-norm). This lets the EXISTING
   0.4–2.1 e-fold data *speak*, with no s-march and no T4.
   **Step 0:** confirm `polar_spectrum.py` persists P (or regenerate it via its
   Lyapunov solve). **Caveat:** P only certifies contraction near the fixed point;
   large excursions fall outside it — but near-field is exactly where the current
   data lives.
2. **Optimal-transient direction.** Compute the input achieving the peak growth
   (leading right singular vector of `e^{tL}` at t\*, or from P) and check whether
   it aligns with the aspect (ℓ_r vs ℓ_z) mode. If it does, the linear obstruction
   and the physical two-scale finding are the same object — a beautiful, cheap
   cross-check. Eigenvalue-free.
3. **DMD on the existing snapshots.** Model-free dynamic mode decomposition on the
   `features.py` snapshot sequences (n≈44/run). If wandering carries a limit-cycle
   frequency or a slow drift mode, DMD surfaces it. Inherits the short-window
   limitation but is a genuinely different lens than slope-fitting.
