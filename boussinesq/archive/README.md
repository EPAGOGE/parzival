# archive

Superseded experiment scripts, kept for provenance rather than use. Nothing
here is referenced by the verification path.

They are retained because several of them produced results that were later
retracted, and the record of how a wrong number was generated is worth as much
as the number that replaced it. See `../STANDARD.md` for the grading rules and
`../faults_freshpass.py` for the six-reviewer fault registry that invalidated
some of this work.

To reproduce anything current, use the scripts in the parent directory.
